# Netflix Content Analysis Dashboard 📊

## Overview
This project analyzes Netflix content using Power BI. The dashboard provides insights into content distribution by year, type, country, and genre.

## Tools Used
- Power BI
- Excel / CSV Dataset

## Key Insights
- Rapid growth in content after 2016
- Movies dominate Netflix catalog (~96%)
- United States produces most content
- Drama and International genres are most common
